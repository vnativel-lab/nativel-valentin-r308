# TP1 · R3.08 — Gestion de données et mini-jeux

Python 3.10+. Lancer chaque fichier depuis ce dossier : `python partie_a_etudiants.py`, etc.

| Fichier | Contenu |
|---|---|
| `partie_a_etudiants.py` | Dictionnaire nom → note, `ajouter_etudiant`, `moyenne_classe`, `meilleur_etudiant`, sauvegarde/rechargement `notes.txt` |
| `partie_b_devine.py` | Devine le nombre (1–100, 10 essais) + bonus rejouer / bornes personnalisées |
| `partie_c_mots.py` + `mots.txt` | `charger_mots`, `choisir_mot` (majuscules), `masque` |
| `partie_d_pendu.py` | Pendu (7 erreurs), ASCII art, mode 2 joueurs, gestion des accents |
| `bonus_hall_of_fame.py` | Rejouer (o/n), scores persistants dans `scores.txt`, mode tournoi (mot choisi par le voisin) |
